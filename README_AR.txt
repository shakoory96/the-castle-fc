THE CASTLE | النسخة الأولية التفاعلية
===================================

كيفية التشغيل:
1. افتح ملف index.html في متصفح Chrome أو Edge أو Firefox.
2. تصفح الصفحات من القائمة. على الهاتف استخدم الشريط السفلي.
3. ادخل إلى "الإدارة" لإضافة لاعبين، مباراة قادمة، نتائج، تقييمات وإنجازات.
4. يمكنك حذف بيانات العرض والبدء ببيانات فارغة من قسم "بيانات المعاينة" في الإدارة.

الوظائف الحالية:
- الرئيسية بمؤشرات الفريق وتفاصيل المباراة القادمة.
- بطاقات لاعبين وملفاتهم وصورهم وتقييماتهم.
- تصنيف رقمي للفريق يعتمد على تقييمات يضيفها المسؤول.
- مركز نتائج ومباريات وتفاصيل المشاركين.
- تصويت على نجم الجمهور وتوقع للنتائج في المتصفح نفسه.
- سجل للبطولات والإنجازات مع إمكانية إضافة جوائز.
- إنشاء بطاقة لاعب PNG للمشاركة.
- تصميم متجاوب مع الكمبيوتر والموبايل، بهوية الشعار الأصلي وألوانه.

تنبيهات مهمة:
- هذه نسخة تجريبية (Prototype)، وليست موقعاً رسمياً منشوراً أو نظاماً إنتاجياً.
- جميع الأسماء والتقييمات والنتائج الأولية بيانات تجريبية، وليست حقائق عن الفريق.
- تُحفَظ الإضافات داخل المتصفح باستخدام localStorage، ولا تتزامن بين الأجهزة.
- لا يوجد تسجيل دخول أو صلاحيات للإدارة؛ لا تعتمدها للجمهور دون إضافة Backend ومصادقة وصلاحيات وحماية قاعدة البيانات.
- تصويت الجمهور محلي ولا يوفر حماية حقيقية من التصويت المتكرر عبر أجهزة أخرى.
- المعادلة الحالية للتقييم للمراجعة فقط: التقييم الجديد = 75% من التقييم القديم + 25% من درجة الأداء الحالية (من 100).
- صورة الشعار الأصلية مدمجة داخل index.html دون إعادة رسمها، والملف الأصلي مرفق أيضاً.

الخطوات التالية المقترحة:
1. إدخال اللاعبين الحقيقيين وصورهم ومراكزهم بعد موافقة الفريق.
2. اعتماد معايير تقييم عادلة للحراس والمدافعين والوسط والمهاجمين.
3. ربط قاعدة بيانات Supabase مع مصادقة وصلاحيات وسجل تدقيق لتصبح البيانات مشتركة بين الأجهزة.
4. استضافة المنصة على نطاق خاص أو خدمة مناسبة وإطلاقها رسمياً.
